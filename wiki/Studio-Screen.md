# Studio Screen

The studio is the same in the desktop program and in the [[Client]]. (The [[Web Studio]] is a lighter page for the same server.)

![Studio](images/screens/client-studio.png)

## Header

- **AUTO / MANUAL / OFFLINE**: automation on, only the playlist, or stopped.
- **Layout**: classic, simple or wide.
- **LIVE**: starts or stops a [[Live Rebroadcast]] source (right-click to choose another).
- **Control Panel**: all the settings.
- **Volume** of the main output and, next to it, the number of **listeners** that are connected to your internet broadcasts (the sum of all servers).

## Deck

The next song, the countdown, the **waveform** with the mix marks, the VU meters and the buttons: Restart, Loop, Pause, Stop after track. The neon **clock** has the minutes as a ring outside and the seconds as a thin ring inside.

## Left: the playlist

Rows have the colours of the library tabs (songs blue, spots green, jingles yellow, assets grey, sweepers purple, voice red). Double-click plays an item; the headphones button previews it; Move Up / Down changes the order; **EXACT TIME** items start at their time. **Delete** removes the selected item from the playlist; the library record stays.

## Centre: the libraries

Tabs: Songs, Spots, Jingles, Assets, Sweepers, Voice, Memos. Search, then add to the end of the playlist or as next.

## Right: instant jingles and Central

Instant jingle pallets: a click plays the jingle on top of the music. Right-click a button to assign, clear or colour it. **Central** shows the history, the coming ad breaks, problems (for example a missing file) and the memos.

## Default shortcuts

F1 next · F2 pause · F3 stop · F4 restart · F5 loop · F6 stop after track · F7 stop jingles. You can change them in **Control Panel > Shortcuts**.

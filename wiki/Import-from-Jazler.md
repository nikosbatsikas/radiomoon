# Import from Jazler / MegaMix

**Control Panel > Utilities > Import from Jazler / MegaMix**.

1. Select the old `.mdb` database (Access 2000-2003; newer Access formats must first be saved as Access 2000) and press **Scan file**. The type (Jazler RadioStar 2 or MegaMix) is detected automatically.
2. Choose what to import: songs, spots and campaigns, playlists, jingle pallets, play history.
3. Press **Start import**.

- If the audio files are on another drive or folder, use the old and new **path start** fields.
- With a [[Client]], tick the option to **upload the files to the server and change the paths**: every imported file is copied to the server.
- Existing data is never overwritten: known file paths and same-named categories, playlists, campaigns and pallets are skipped. User passwords are not imported. For MegaMix the music sequence rules are not converted.

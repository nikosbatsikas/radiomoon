Adding a language to RadioMoon
-------------------------------
1. Copy template.json to a new file named with the language code, for example de.json.
2. Change "_name" to the name of the language as it should appear in the language list.
3. Translate the text on the right side of each line. Keep placeholders such as {date} as they are.
   Texts that are missing in the file are shown in English.
4. Put the file in the "lang" folder next to the program (or in the "lang" folder of the data folder)
   and choose the language in Control Panel > General settings > Language.
English and Greek (Ελληνικά) are built in.
